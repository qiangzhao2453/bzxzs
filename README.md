# 百战客服小助手 — 多意图识别智能客服系统

基于Coze平台搭建的多意图智能客服工作流与智能体，已通过Chat SDK嵌入网页端上线运行。

## 🔗 在线体验

- **Coze Bot体验**：https://www.coze.cn/s/nQbgOgw6WkE/
- **网页嵌入版**：https://qiangzhao2453.github.io/bzxzs/

## 🎯 项目背景

在学习和实践AI智能体过程中，针对企业客服场景中"用户问题类型多样、单一Prompt无法准确处理、需要分流到不同处理逻辑"的痛点，设计了一套多意图识别+分支路由的客服工作流方案。

## 🏗️ 系统处理流程

1. **用户输入**：接收用户消息
2. **意图识别**(LLM Router)：LLM自动分类用户意图类型
3. **分支路由**（选择器节点）：根据意图分发到对应处理分支
   - 📚 **知识库检索**(RAG问答)：产品咨询类 → 知识库检索增强生成
   - 💬 **固定回复**(FAQ匹配)：高频标准问题 → 直接匹配FAQ回复
   - 👤 **人工转接**(转人工)：投诉/复杂问题 → 触发人工转接流程
   - 😊 **闲聊处理**(寒暄回复)：寒暄问候 → 自然回复
4. **回复生成 & 输出**：汇总分支结果返回给用户

## ✨ 核心功能

- **多意图识别**：使用LLM作为分类器，自动判断用户意图类型（产品咨询/售后问题/投诉建议/闲聊/需要人工）
- **选择器路由**：根据意图识别结果，自动将对话分发到对应处理分支
- **RAG知识库问答**：接入知识库，针对产品咨询类问题进行检索增强生成
- **固定回复分支**：高频标准问题直接匹配FAQ回复，保证响应速度和一致性
- **人工转接**：识别到投诉、复杂问题时触发人工转接流程
- **网页嵌入**：通过Coze Chat SDK将Bot嵌入网页，支持自定义UI样式

## 🛠️ 技术栈

- **平台**：Coze（扣子）
- **核心能力**：工作流编排、LLM意图分类、选择器节点、知识库RAG
- **部署**：Coze Chat SDK + HTML网页嵌入
- **调优**：Prompt Engineering、知识库分段策略、多轮测试迭代

## 📝 设计思路

1. **意图分类体系设计**：将客服场景常见问题拆解为可枚举的意图类别，每个类别对应明确的处理策略
2. **选择器节点逻辑**：根据意图分类置信度和关键词，决定走哪条处理分支，避免误路由
3. **知识库分段优化**：调整chunk size和overlap参数，提升检索准确率
4. **Prompt调优**：通过多轮测试优化意图分类Prompt，减少误分类case
5. **兜底策略**：置信度低于阈值时走人工转接，保证用户体验
